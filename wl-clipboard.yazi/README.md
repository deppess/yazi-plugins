# wl-clipboard.yazi

Copies selected or hovered files to the Wayland system clipboard as `text/uri-list` data.

Requires [`wl-clipboard`](https://github.com/bugaevc/wl-clipboard) (make sure `wl-copy`/`wl-paste` are on your `$PATH`).

Derived from [grappas/wl-clipboard.yazi](https://github.com/grappas/wl-clipboard.yazi), itself derived from [orhnk/system-clipboard.yazi](https://github.com/orhnk/system-clipboard.yazi). This is the Linux/Wayland counterpart to [system-clipboard.yazi](../system-clipboard.yazi).

## Installation

```sh
ya pkg add deppess/yazi-plugins:wl-clipboard
```
